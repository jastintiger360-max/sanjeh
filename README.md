# سنجه — سامانه طراحی سؤال، بانک سؤال هوشمند و آزمون آنلاین

> نام «سنجه» پیشنهادی است و از «تنظیمات ← هویت سامانه» قابل تغییر است.

## اجرای سریع
```bash
cp .env.example .env        # ADMIN_PASSWORD و AI_API_KEY را تنظیم کنید
node --version              # حداقل 22.13
npm start                   # http://localhost:8080
npm test                    # ۲۸ آزمون خودکار (واحد + سناریوهای سرتاسری)
```
با Docker: `docker compose up -d --build` (شامل poppler و tesseract فارسی).

پیش‌نیازهای سیستمی برای استخراج: `pdftotext`/`pdftoppm` (poppler-utils) و `tesseract` با داده زبان `fas`.

## معماری
سه هسته روی یک پایگاه داده مرکزی، با مرزبندی سمت سرور:
1. **پنل طراح** (`/admin`، API `/api/admin/*`): کد این پنل فقط به نشست مدیر تحویل داده می‌شود.
2. **موتور هوشمند** (`src/ai`): بازیابی شواهد (RAG با BM25 و embedding اختیاری) ← طراح ← آزمون‌های قطعی نرم‌افزاری ← منتقد مستقل ← حل‌کننده مستقل (بدون کلید، گزینه‌های جابه‌جاشده) ← جمع‌بندی نرم‌افزاری.
3. **پنل دانش‌آموز** (`/student`، API `/api/student/*`).

| لایه | انتخاب | دلیل |
|---|---|---|
| Backend | Node.js 22، بدون وابستگی خارجی | قابل ممیزی، بدون زنجیره تأمین npm |
| DB | SQLite (پیش‌فرض، WAL) / PostgreSQL (آداپتور) | رابط async یکسان |
| Auth | scrypt، نشست HttpOnly + SameSite=Strict، توکن CSRF | |
| Frontend | ES Modules بدون build، RTL، Vazirmatn | CSP سخت‌گیر بدون اسکریپت درون‌خطی |

### جداول اصلی
`users, student_groups, group_members, sessions, audit_logs, settings, sources, source_pages, source_chunks, generation_jobs, ai_calls, questions, question_versions (تغییرناپذیر), question_events, exams, exam_questions (اشاره به نسخه دقیق), exam_assignments, attempts, attempt_answers`

### قواعد کلیدی پیاده‌شده
- بانک = فقط سؤال‌هایی که «نسخه تأییدشده مدیر» دارند. ویرایش، نسخه جدید می‌سازد؛ آزمون‌ها به نسخه دقیق اشاره می‌کنند.
- نقل‌قول شاهد هر سؤال به‌صورت نرم‌افزاری با متن منبع تطبیق داده می‌شود.
- شواهد ناکافی ← امتناع پیش از فراخوانی مدل. بدون کلید API ← خطای صریح ۵۰۳، بدون خروجی ساختگی.
- تایمر سمت سرور، تحویل خودکار، seq یکنوا برای حل تعارض پاسخ‌ها، ذخیره محلی هنگام قطع اینترنت.
- کلید پاسخ و پاسخ تشریحی فقط طبق سیاست زمانی آزمون به دانش‌آموز ارسال می‌شود.

## وضعیت صادقانه (نسخه 0.1)
- ✅ آزمون‌شده خودکار: همه ۱۵ سناریوی بخش پانزدهم روی سرور HTTP واقعی + SQLite (`tests/e2e.test.js`). موتور هوش مصنوعی با یک سرور جعلی سازگار با OpenAI در **فقط محیط تست** آزموده شد؛ مسیر کد واقعی HTTP همان است.
- ⚠️ با مدل واقعی اجرا نشده (محیط توسعه اینترنت نداشت). کیفیت سؤال‌ها را با منابع واقعی بسنجید و پرامپت‌ها (`src/ai/prompts.js`) را تنظیم کنید.
- ⚠️ آداپتور PostgreSQL نوشته شده اما اجرا نشده: پیش از استقرار `DB_DRIVER=postgres npm test`.
- ⚠️ PDF فارسی: لایه متنی بسیاری از PDFها (لیگاتور «لا»، ترتیب خطوط ترکیبی) خراب استخراج می‌شود؛ سامانه این صفحات را علامت می‌زند و OCR فارسی را امتحان می‌کند. برای کتاب‌های اصلی «پردازش با OCR» یا نسخه Word توصیه می‌شود.
- ⚠️ خروجی PDF از طریق نسخه چاپی مرورگر (Save as PDF) است، نه تولید PDF سمت سرور.
- ⚠️ رابط کاربری از نظر نحوی بررسی شده اما در مرورگر واقعی آزمون دستی نشده است.
- محدودکننده نرخ در حافظه است؛ برای چند نمونه سرور، محدودیت را در reverse proxy هم بگذارید.

## استقرار
پشت Nginx با HTTPS، `PUBLIC_ORIGIN=https://…` (کوکی Secure و HSTS فعال می‌شود)، `TRUST_PROXY=1`.
پشتیبان: `npm run backup` در cron (SQLite + فایل‌های منابع)؛ برای Postgres از `pg_dump`.
